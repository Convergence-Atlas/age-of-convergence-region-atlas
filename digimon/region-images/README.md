# First Light region illustrations

37 individual environment views extracted from the existing Digimon illustration sheets and encoded as JPEGs at quality 94.

These are original campaign illustrations, not official game maps. Selected new game regions reuse suitable existing location or area scenes. No new scenes were generated. Exact source boards, rectangles and Git blob hashes are recorded in manifest.json.

Voyage Regions JSON uses images.map.imageUrl with crop.focus at 50/50 and crop.zoom at 100. The map image is a regional establishing illustration; actual travel follows the campaign's established locations and gate rules.

The Regions replacement preserves all 21 supplied keys and adds 16 regions. It uses only existing realm and faction identifiers. It does not import NPCs or abilities.

The numeric NPC level ranges guide generated encounters, not published Digimon growth stages. A location's own range takes priority, and explicit named-NPC levels are preserved.
